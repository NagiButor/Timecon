# Проверка Rust-версии

## Воспроизводимые проверки

```sh
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo clippy --target wasm32-unknown-unknown --package timecon --locked -- -D warnings
cargo test --workspace --locked
cargo xtask build
cargo xtask serve
```

Модульные тесты покрывают старый JSON, миграцию одиночного таймера и зарплаты, параллельные таймеры, отмену, конфликт статусов, переносы без дубликатов, сохранение порядка, метки удаления, календарь, выплаты в выходные, CSV и безопасный HTML.

## Браузерная проверка

При миграции выполнены headless-проверки в Microsoft Edge с мобильным viewport 390 × 844. Все сценарии прошли без JavaScript/WASM ошибок:

- Первый запуск, обучение и пять вкладок.
- Создание двух задач, параллельный старт, перезагрузка с активными таймерами, отмена и выполнение без таймера.
- Сохранение/применение пресета, перенос в отложенные и возврат.
- Заметки: название, Unicode-текст, Rust-подсветка, загрузка и сжатие фото, повторное открытие.
- Доход, расход, баланс месяца и статистика.
- Смена языка и темы, JSON-экспорт.
- Установка Rust service worker, кэширование WASM, полное отключение сети, перезагрузка и сохранение активного таймера.
- Миграция одиночного таймера v31, обработка истёкшего таймера и результата, автозапуск, старое расписание зарплаты, заметки и JSON-импорт.
- Отсутствие горизонтального переполнения при ширине экрана 360 px.

Supabase проверен через изолированную подмену HTTP-ответов, без регистрации или изменения production-данных:

- Отправка запроса восстановления пароля, вход и первичная загрузка состояния.
- Отложенная отправка изменений и сброс dirty-флага только для отправленной версии.
- Обновление истёкшей сессии refresh-токеном.
- Применение более свежего результата задачи с сервера.
- Выход и очистка сессии.

## Ручная проверка перед использованием

С реальным аккаунтом проверь Google OAuth, доставку письма восстановления и мгновенный обмен изменениями между двумя устройствами. Для сигналов в iOS PWA требуются поддерживаемая версия iOS, установка на экран «Домой» и разрешения; браузер не гарантирует исполнение таймера при закрытом приложении.

Обновление со старого сайта: открой новую версию, закрой все её окна, открой снова, проверь `v32 · Rust` в настройках. До обновления рекомендуется сохранить JSON-экспорт. Миграция использует прежние localStorage и Supabase, изменения SQL не нужны.
