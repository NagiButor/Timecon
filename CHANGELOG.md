# Изменения

## v32 — Rust / WebAssembly

- Полностью заменено JavaScript-приложение: логика, интерфейс и браузерные обработчики теперь написаны на Rust и компилируются в WebAssembly.
- Перенесены задачи с параллельными таймерами, подтверждение результата, автозапуск и отмена, переносы, сортировка, пресеты, отложенные задачи.
- Перенесены блочные заметки, сжатие фото до 1280 px, подсветка и определение языка кода; добавлена поддержка Rust.
- Перенесены статистика, доходы/расходы, выплаты с переносом выходных, категории, темы, русский и английский интерфейс, обучение.
- Реализованы Supabase REST/Auth/Realtime без JS SDK: email/password, Google, восстановление пароля, refresh сессии, очередь и резервная синхронизация.
- Сохранена совместимость с `timecon.v1`, JSON-резервными копиями, старым форматом активного таймера и расписания выплат.
- Добавлены метки удаления и объединение задач по уникальному ID независимо от дня: удалённые записи не воскресают, перенесённые не дублируются.
- Добавлены резервирование повреждённого JSON, безопасное экранирование интерфейса и нейтрализация формул в CSV.
- Service worker и политика офлайн-кэширования перенесены на Rust. JS-загрузчики WASM генерируются автоматически; исходный JS и архив v19 удалены.
- Добавлены Cargo workspace, воспроизводимый lockfile, Rust-команды сборки/preview, тесты и GitHub Actions для проверки и публикации Pages.

### Развёртывание

GitHub Pages должен использовать **GitHub Actions**, а не публикацию корня ветки. Workflow собирает и публикует `dist/`; домен `timecon.space`, стили, шрифты и значки сохранены.

### Ограничения проверки

Автоматические проверки не используют личные данные и не регистрируют пользователей в production Supabase. Живой вход Google, доставка писем и межустройственная синхронизация требуют проверки с реальным аккаунтом.
