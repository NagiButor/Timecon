# Демонстрация Timecon

Скриншоты сняты с работающей Rust / WebAssembly-версии приложения на основе коммита `1831004`, с мобильным viewport 420 × 1000 CSS px. Это реальные экраны, не макеты и не изображения обучения.

Все задачи, заметки, суммы и операции вымышлены. Демонстрация выполнена локально в изолированном браузере: вход в аккаунт не выполнялся, запросы к production Supabase заблокированы.

## Файлы

- `walkthrough.gif` — 20-секундная демонстрация формы задачи, запуска и отсчёта таймера, переходов между вкладками и светлой темы.
- `tasks.png` — план дня с активным таймером, ожидающей и выполненной задачами.
- `notes.png` — список демонстрационных заметок.
- `note-editor.png` — заметка с текстовым блоком и подсветкой Rust.
- `stats.png` — статистика за неделю по задачам и категориям.
- `finance.png` — баланс, доходы, расходы и категории трат.
- `light-theme.png` — план дня в светлой теме.

Для стабильных кадров время браузера зафиксировано на 10 ноября 2026 года. Отсчёт показан последовательным продвижением времени браузера через `60:00`, `59:59` и `59:58`; значения рисует сам таймер приложения. В GIF добавлены только подписи над кадрами; интерфейс на снимках не изменялся.
