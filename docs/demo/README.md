# Демонстрация Timecon

Скриншоты сняты с работающей Rust / WebAssembly-версии приложения, с мобильным viewport 420 × 1000 CSS px. Это реальные экраны, не макеты и не изображения обучения.

`day-plan.png`, `task-form.png`, `finance.png` и `light-theme.png` обновлены для v33. Снимки таймера, заметок, статистики и GIF показывают интерфейс v32 на основе коммита `1831004`.

`daily-form.png` и `daily-tasks.png` сняты в v34: параметр ежедневного повтора и автоматически заполненный план следующего дня.

Все задачи, заметки, суммы и операции вымышлены. Демонстрация выполнена локально в изолированном браузере: вход в аккаунт не выполнялся, запросы к production Supabase заблокированы.

## Файлы

- `daily-form.png` — создание задачи с параметром «Повторять каждый день».
- `daily-tasks.png` — следующий день с отдельными экземплярами ежедневных задач без таймера и с таймером.
- `walkthrough.gif` — 20-секундная демонстрация формы задачи, запуска и отсчёта таймера, переходов между вкладками и светлой темы.
- `day-plan.png` — смешанный план дня: обычные задачи без таймера, задача с длительностью и выполненное дело.
- `task-form.png` — форма добавления с выбором «Без таймера / С таймером».
- `tasks.png` — план дня с активным таймером, ожидающей и выполненной задачами.
- `notes.png` — список демонстрационных заметок.
- `note-editor.png` — заметка с текстовым блоком и подсветкой Rust.
- `stats.png` — статистика за неделю по задачам и категориям.
- `finance.png` — баланс, зелёная сумма доходов, красная сумма расходов и категории трат.
- `light-theme.png` — смешанный план дня v33 в светлой теме.

Для стабильных кадров время браузера зафиксировано: 10 ноября 2026 года в материалах v32, 12 ноября — в новых снимках v33. Отсчёт в GIF показан последовательным продвижением времени браузера через `60:00`, `59:59` и `59:58`; значения рисует сам таймер приложения. В GIF добавлены только подписи над кадрами; интерфейс на снимках не изменялся.
